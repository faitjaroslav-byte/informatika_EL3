# Kapitola 4 - Data, grafy a důkazy

<div class="lesson-meta">
<strong>Doporučený čas:</strong> 6-8 vyučovacích hodin<br>
<strong>Výstup kapitoly:</strong> Vytvoříš datový slide, který ukazuje pravdivý závěr, používá vhodný typ grafu a vede pozornost k hlavní pointě.
</div>

## Motivace

Data mohou prezentaci dodat sílu. Mohou ukázat změnu, rozdíl, problém nebo důkaz. Zároveň ale patří mezi nejčastější zdroje nepřehledných slidů. Tabulka plná čísel na projekčním plátně publiku obvykle nepomůže. Publikum nemá čas hledat, co je důležité.

Datové slidy nejsou hlavně o datech. Jsou o významu dat. Cílem není ukázat všechno, co máme, ale vysvětlit, co z toho plyne.

## Co se naučíš

- formulovat závěr ještě před tvorbou grafu,
- vybrat graf podle sdělení,
- rozlišit číslo, graf, tabulku a handout,
- používat zvýraznění v datovém slidu,
- zkontrolovat, zda graf nelže nebo nemate.

## Výklad

### Pět pravidel datového slidu

Práci s daty v prezentaci můžeme shrnout do pěti pravidel:

| Pravidlo | Význam pro školní prezentaci |
| --- | --- |
| `Tell the truth` | Graf nesmí zkreslovat měřítko, hodnoty ani souvislosti. |
| `Get to the point` | Nejdřív urči závěr, potom vybírej graf. |
| `Pick the right tool for the job` | Jiný graf se hodí pro podíl, jiný pro trend, jiný pro porovnání. |
| `Highlight what’s important` | Publikum má rychle poznat, kam se dívat. |
| `Keep it simple` | Na slidu nemá být víc detailů, než je potřeba k pochopení pointy. |

### Nejdřív závěr

Špatný datový slide často vzniká tak, že autor vybere tabulku, vloží graf a potom se snaží vysvětlit, co graf znamená. Lepší postup je opačný:

1. Co chci, aby si publikum z dat odneslo?
2. Která hodnota, rozdíl nebo změna to dokazuje?
3. Jaký typ zobrazení tuto myšlenku ukáže nejrychleji?
4. Co mohu odstranit, aby pointa nezanikla?

Příklad: Pokud je hlavní zpráva "většina třídy používá jednu aplikaci", možná není potřeba složitý graf. Stačí velké číslo s krátkým vysvětlením. Pokud je hlavní zpráva "zájem postupně klesá", bude vhodnější čárový graf.

### Volba grafu

| Chci ukázat | Vhodný výstup |
| --- | --- |
| jedno silné číslo | samotné číslo, případně s krátkým popisem |
| porovnání kategorií | sloupcový graf |
| změnu v čase | čárový graf |
| části jednoho celku | koláčový graf, jen u malého počtu částí |
| přesné hodnoty pro pozdější čtení | tabulka v dokumentu nebo handoutu |

Koláčový graf se často používá zbytečně. Hodí se hlavně tehdy, když ukazuje části jednoho celku a hodnoty dohromady dávají 100 %. Pro přesné porovnání více položek bývá přehlednější sloupcový graf.

### Vrstvy datového slidu

Datový slide můžeš chápat jako tři vrstvy:

| Vrstva | Úloha |
| --- | --- |
| background | osy, měřítko, legenda, kontext |
| data | samotné hodnoty nebo křivky |
| emphasis | zvýraznění toho, co je nejdůležitější |

Background má být klidný. Data mají být čitelná. Emphasis má vést oko k závěru. Když je všechno výrazné, není výrazné nic.

### Pravdivost a čitelnost

Graf může mást i tehdy, když čísla nejsou vyloženě špatně. Časté problémy:

- osa nezačíná tam, kde publikum očekává,
- různé grafy používají různé měřítko,
- barvy zdůrazňují méně důležitou část,
- legenda je daleko od dat,
- graf ukazuje příliš mnoho řad najednou,
- nadpis popisuje téma, ale neříká závěr.

Dobrá kontrolní otázka zní: "Pochopí publikum hlavní závěr do několika sekund?"

### Doplněno pro tuto učebnici: práce s tabulkou

Ve školním projektu budou data často vznikat v tabulkovém editoru. Tabulka je dobrá pro výpočty a kontrolu hodnot, ale ne vždy pro prezentaci. Proto odděluj pracovní soubor od prezentačního slidu.

Pracovní tabulka může obsahovat všechny hodnoty, poznámky a výpočty. Slide má obsahovat jen vybrané údaje, které podporují `message`. Pokud publikum potřebuje přesná data, přilož tabulku jako dokument nebo odkaz.

## Praktický úkol

Získej jednoduchá data, například anonymní anketu ve třídě. Téma může být používání aplikací, doprava do školy, délka přípravy na test nebo oblíbený způsob učení.

1. Vytvoř pracovní tabulku.
2. Napiš jeden závěr, který z dat vyplývá.
3. Vyber vhodný typ grafu.
4. Vytvoř slide, který ukazuje jen tento závěr.
5. Použij zvýraznění jedné hodnoty nebo části grafu.
6. Zkontroluj, zda graf nelže měřítkem nebo popisem.

## Tahák

| Kontrola | Otázka |
| --- | --- |
| pravda | Nezkresluje graf hodnoty? |
| pointa | Je závěr jasný předem? |
| nástroj | Odpovídá typ grafu sdělení? |
| zvýraznění | Vím hned, kam se dívat? |
| jednoduchost | Neobsahuje slide zbytečné detaily? |
